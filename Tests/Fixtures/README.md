# Test fixtures

Small, committed inputs the test suites read. Nothing here is user data.

## Face images

These three JPEGs drive the engine's decode, align, embed, and match tests
(`Tests/KionEngineTests/KionEngineTests.swift`) and the app's enrollment tests
(`KiFinderTests/`). Each holds a single, clearly detectable face.

- **`face_a.jpg`**: Person A. Tests decoding to exact pixel dimensions, face alignment,
  embedding, and bit-reproducibility of the ArcFace embedding against
  `face_a_embedding_baseline.json`. It is also the seed for `sample_album.zip`.
- **`face_a2.jpg`**: a **second image of the same person as `face_a`**. Verifies that two
  photos of one person embed close together (high cosine similarity).
- **`face_b.jpg`**: a **distinct person** from `face_a`. Verifies that different people embed
  far apart (low similarity), so a match is not a false positive.

### Provenance

These images were recorded as **two distinct public-domain, consenting, or synthetic faces**,
each with a single clearly detectable face. `face_a2` is a second image of the same person as
`face_a`. **None of them is the app author or the app's subject.** The original **source URLs
were not retained**, so they can't be cited here.

If you are the original author of one of these images and want it removed, please open an
issue and it will be taken down.

## Other fixtures

- **`blank.png`**: a tiny blank image with **no detectable face**. Checks that the pipeline
  rejects faceless images: it yields no face and never lands in keep or maybe.
- **`not-an-image.txt`**: a plain-text file. `KiFinderTests/EnrollmentModelTests.swift` uses it
  to check that enrollment rejects non-image input gracefully.
- **`face_a_embedding_baseline.json`**: a 512-dimensional ArcFace embedding of `face_a.jpg`,
  captured before a change to how the ONNX Runtime shim releases memory. The embedding test re-embeds
  `face_a.jpg` and requires the result to be bit-reproducible and within a tight cosine bound of
  this baseline. This guards against silent numerical regressions.

## Generated (not committed)

- **`sample_album.zip`** is **gitignored** (the repo's `*.zip` rule keeps real albums out of
  git) and **generated by `Scripts/bootstrap-fixtures.sh`**. The script zips the committed
  `face_a.jpg` at the archive root (`zip -X sample_album.zip face_a.jpg`), so the `ScanPipeline`
  zip-extraction tests find `face_a.jpg` in the manifest. To build just the zip without
  downloading any model weights, run `./Scripts/bootstrap-fixtures.sh --skip-model`.
