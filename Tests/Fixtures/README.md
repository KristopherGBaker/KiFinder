# Test fixtures

Small, committed inputs the test suites read. Nothing here is user data.

## Face images

These three JPEGs drive the engine's decode / align / embed / match tests
(`Tests/KionEngineTests/KionEngineTests.swift`) and the app's enrollment tests
(`KiFinderTests/`). Each holds a single, clearly-detectable face.

- **`face_a.jpg`** — Person A. Used to test image decoding to exact pixel dimensions, face
  alignment, embedding, bit-reproducibility of the ArcFace embedding against
  `face_a_embedding_baseline.json`, and as the seed for `sample_album.zip`.
- **`face_a2.jpg`** — a **second image of the same person as `face_a`**. Used to verify that
  two photos of one person embed close together (high cosine similarity).
- **`face_b.jpg`** — a **distinct person** from `face_a`. Used to verify that different
  people embed far apart (low similarity), so a match is not a false positive.

### Provenance

These images were recorded as **two distinct public-domain / consenting / synthetic faces**,
each with a single clearly-detectable face; `face_a2` is a second image of the same person as
`face_a`; **none of them is the app author or the app's subject.** The original **source URLs
were not retained**, so they cannot be cited here.

If you are the original author of one of these images and want it removed, please open an
issue and it will be taken down.

## Other fixtures

- **`blank.png`** — a tiny blank image with **no detectable face**. Used to assert the
  pipeline rejects faceless images (it yields no face at all and never lands in keep/maybe).
- **`not-an-image.txt`** — a plain-text file used by `KiFinderTests/EnrollmentModelTests.swift`
  to verify that enrollment rejects non-image input gracefully.
- **`face_a_embedding_baseline.json`** — a 512-dimensional ArcFace embedding of `face_a.jpg`
  captured on unmodified `main` (before the item-52 shim changes). The embedding test
  re-embeds `face_a.jpg` and requires the result to be bit-reproducible and stay within a
  tight cosine bound of this baseline, guarding against silent numerical regressions.

## Generated (not committed)

- **`sample_album.zip`** — **gitignored** (the repo's `*.zip` rule keeps real albums out of
  git) and **generated by `Scripts/bootstrap-fixtures.sh`**. The script builds it by zipping
  the committed `face_a.jpg` at the archive root (`zip -X sample_album.zip face_a.jpg`), so
  the `ScanPipeline` zip-extraction tests find `face_a.jpg` in the manifest. Run
  `./Scripts/bootstrap-fixtures.sh --skip-model` to build just the zip without downloading
  any model weights.
